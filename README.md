## 🌡️ Projeto 03 — Conversor de Temperatura

![Nível](https://img.shields.io/badge/NÍVEL-INICIANTE-brightgreen)
![Formulários](https://img.shields.io/badge/FOCO-FORMULÁRIOS-blue)

### 🎯 Objetivo

Construir um aplicativo capaz de converter temperaturas entre Celsius, Fahrenheit e Kelvin.

### 📱 Funcionalidades

- Receber a temperatura informada pelo usuário.
- Selecionar a unidade de origem.
- Selecionar a unidade de destino.
- Calcular o resultado automaticamente.
- Exibir o valor convertido.
- Validar os dados digitados.
- Permitir limpar os campos.

### 📐 Fórmulas

**Celsius para Fahrenheit**

F = (C × 9/5) + 32

**Fahrenheit para Celsius**

C = (F − 32) × 5/9

**Celsius para Kelvin**

K = C + 273,15

### 🧠 Conceitos trabalhados

`OutlinedTextField` • `Text` • `DropdownMenu` • `remember` • condicionais • validação

### 🏆 Desafio extra

Criar histórico de conversões e permitir alternar rapidamente as unidades de origem e destino.

### ✅ Resultado esperado

Conversões corretas com validação de entradas e respeito aos limites físicos das escalas.

**📂 Pasta:** `03-conversor-temperatura/`

## 📝 Projeto 10 — Corretor de Provas

![Nível](https://img.shields.io/badge/NÍVEL-AVANÇADO-red)
![Educação](https://img.shields.io/badge/CATEGORIA-EDUCAÇÃO-purple)
![Arquitetura](https://img.shields.io/badge/ARQUITETURA-MVVM-blue)

### 🎯 Objetivo

Criar um sistema mobile para cadastro de avaliações, gabaritos, respostas dos alunos e correção automática de provas objetivas.

### 📱 Funcionalidades

#### 👨‍🏫 Gerenciamento de Avaliações

- Criar uma prova.
- Definir título e disciplina.
- Informar turma.
- Determinar quantidade de questões.
- Cadastrar gabarito oficial.
- Definir pontuação máxima.

#### 👨‍🎓 Cadastro de Alunos

- Cadastrar aluno.
- Informar turma e identificação.
- Associar aluno à avaliação.
- Consultar histórico de avaliações.

#### ✅ Correção Automática

- Registrar respostas do aluno.
- Comparar respostas com o gabarito.
- Identificar alternativas corretas.
- Calcular quantidade de acertos.
- Calcular quantidade de erros.
- Gerar nota final.
- Registrar resultado no banco de dados.

### 📐 Exemplo de cálculo

Considere uma avaliação com:

- 20 questões.
- Valor máximo de 10 pontos.
- 16 respostas corretas.

A nota será calculada por:

**Nota = (Acertos / Total de questões) × Nota máxima**

**Nota = (16 / 20) × 10 = 8,0**

A fórmula considera todas as questões com o mesmo peso.

### 🗄️ Estrutura de dados sugerida

| Entidade | Descrição |
|---|---|
| Aluno | Dados do estudante |
| Turma | Identificação da turma |
| Avaliacao | Informações da prova |
| Questao | Questões da avaliação |
| Gabarito | Respostas corretas |
| Resposta | Alternativas marcadas |
| Resultado | Nota e total de acertos |

### 🧠 Conceitos trabalhados

Room • MVVM • Navigation Compose • Kotlin Flow • relacionamentos de entidades • regras de negócio • relatórios

### 🏆 Desafio extra — Correção por câmera

Desenvolver uma funcionalidade que permita:

1. Abrir a câmera do dispositivo.
2. Fotografar um cartão-resposta.
3. Identificar as marcações por processamento de imagem.
4. Apresentar as alternativas reconhecidas.
5. Permitir conferência e correção manual.
6. Comparar respostas com o gabarito.
7. Calcular e salvar a nota.

Essa funcionalidade pode utilizar CameraX e técnicas de visão computacional.

A leitura automática deve ser validada antes de salvar os resultados, especialmente quando houver marcações ambíguas.

### 🔐 Proteção de Dados

Ao trabalhar com dados reais de estudantes, observar os princípios da LGPD e implementar controles adequados de acesso e armazenamento.

### ✅ Resultado esperado

Um sistema educacional que permita cadastrar, corrigir e consultar avaliações de forma consistente e auditável.

**📂 Pasta:** `10-corretor-provas/`

# ▶️ Como Executar os Projetos

## 1. Instalar o Android Studio

Faça o download pelo site oficial:

https://developer.android.com/studio

Configure o Android SDK e um dispositivo virtual.

## 2. Obter o Repositório

Clone utilizando Git:

```bash
git clone URL_DO_REPOSITORIO
```

Ou selecione:

**Code → Download ZIP**

## 3. Abrir o Projeto

No Android Studio:

1. Clique em **Open**.
2. Selecione a pasta do aplicativo desejado.
3. Aguarde a sincronização do Gradle.
4. Configure o emulador ou dispositivo físico.
5. Clique em **Run ▶**.

Se a pasta do projeto ainda não existir, crie o aplicativo utilizando o template **Empty Activity**, com Kotlin e Jetpack Compose.

# 🎨 Boas Práticas de Desenvolvimento

Todos os projetos devem seguir boas práticas:

- Utilizar Kotlin como linguagem principal.
- Construir interfaces com Jetpack Compose.
- Priorizar componentes reutilizáveis.
- Manter nomes de variáveis e funções claros.
- Utilizar estado de maneira consistente.
- Separar interface e regras de negócio.
- Validar entradas dos usuários.
- Tratar situações inesperadas.
- Testar diferentes tamanhos de tela.
- Utilizar Material Design 3.
- Evitar credenciais e tokens no GitHub.
- Documentar decisões técnicas importantes.
